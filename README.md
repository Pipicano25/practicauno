# practicauno

Práctica básica de HTML con páginas de ejemplo que muestran encabezados y texto de relleno. Sirve como primer ejercicio de estructura HTML.

## Tecnologías

- HTML

## Uso

Abrir `htmluno.html`, `htmldos.html` o `index2.html` en un navegador para ver el contenido.

## Estructura

- `htmluno.html` — encabezados "hola" y "mundo".
- `htmldos.html` — encabezados "hola", "mundo" y "gracias".
- `index2.html` — texto de relleno (Lorem ipsum).
